# 🚀 Erronka de Clase

## 📌 Descripción
Este proyecto forma parte de una erronka realizada en clase. El objetivo es poner en práctica los conocimientos adquiridos durante el curso, trabajando en equipo y desarrollando una solución al reto propuesto.

## 🎯 Objetivos
- Aplicar los conocimientos aprendidos en clase.
- Desarrollar una solución funcional.
- Mejorar el trabajo en equipo.
- Documentar el proceso de desarrollo.

- Git y GitHub

## ⚙️ Instalación y ejecución
1. Clona el repositorio:
   ```bash
   git clone URL_DEL_REPOSITORIO
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd erronka
   ```
3. Abre el archivo `index.html` en tu navegador.
